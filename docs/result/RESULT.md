# Fruit App Итоги реализации

Приложение разработано на **Flutter 3.35.7** / **Dart 3.9.2** и поддерживает работу на Android и iOS.

## 1. Краткое описание проекта

**Fruit App** - это nutrition-tech приложение, которое позволяет:

- просматривать фрукты из публичного API Fruityvice;
- сортировать и фильтровать фрукты;
- просматривать пищевую ценность;
- добавлять фрукты в избранное и хранить их локально;
- создавать рецепты из избранных фруктов и сохранять их на устройстве;
- смотреть суммарные показатели по рецепту.

## 2. Архитектура и структура проекта

Проект разделён на слои:

- **data**  
  - модели: `Fruit`, `Nutrition`, `Recipe`, `RecipeWithDetails`;  
  - сетевой слой: `FruityviceApiService` (пакет `http`);  
  - локальное хранилище: `LocalStorageService` на `SharedPreferences`;  
  - репозитории: `FruitRepository`, `RecipeRepository`.

- **domain**  
  - контракты репозиториев (`FruitRepositoryBase`, `RecipeRepositoryBase`);  
  - вспомогательные структуры для агрегации данных.

- **presentation**  
  - состояние: `FruitsViewModel`, `RecipesViewModel`, `FruitFilters`;  
  - экраны:
    - список фруктов;
    - экран фильтрации/сортировки;
    - детальный экран фрукта;
    - избранное;
    - список рецептов;
    - создание рецепта;
    - редактирование рецепта;
    - просмотр рецепта.

Использованы паттерны:

- MVVM;
- Repository;
- Service;
- управление состоянием через Provider;
- разделение UI / бизнес-логики / данных.

## 3. Работа с API

Используется открытый API Fruityvice:

- `GET https://www.fruityvice.com/api/fruit/all`

Особенности реализации:

- загрузка списка фруктов при старте;
- данные кешируются в памяти, сортировка и фильтрация выполняются локально;
- обработка ошибок сети (состояния: загрузка, ошибка, успешная загрузка);
- повторная попытка по кнопке «Повторить».

## 4. Локальное хранилище

### Избранное

- Хранится список ID избранных фруктов.
- При запуске приложения:
  - из API приходит полный список фруктов;
  - по списку ID из локального хранилища восстанавливается список избранных.
- При добавлении/удалении избранного локальное хранилище обновляется.

### Рецепты

Каждый рецепт хранит:

- id (генерируется локально);
- название;
- описание;
- список ID фруктов.

Данные сериализуются в JSON и сохраняются в `SharedPreferences`.  
При чтении:

- по ID фруктов подтягиваются данные из общего списка фруктов;
- рассчитываются суммарные нутриенты (калории, жиры, сахар, углеводы, белок).

## 5. Реализованные экраны

### 5.1. Вкладка «Фрукты»

- Загрузка фруктов из API.
- Состояния:
  - загрузка (лоадер);
  - ошибка (текст + кнопка «Повторить»);
  - успешная загрузка (список).
- Карточка фрукта:
  - название;
  - семейство;
  - короткие данные по питательной ценности;
  - иконка «избранное».
- По нажатию на карточку — переход на экран детальной информации.
- Кнопка сортировки в AppBar → переход на экран фильтров и сортировки.
- Плавающая кнопка «стрелка вверх» при прокрутке вниз.

### 5.2. Экран «Фильтры»

- Варианты сортировки:
  - по названию (A-Z, Z-A);
  - по калориям (возрастание, убывание).
- Набор преднастроенных фильтров (например, по калориям, сахару и т.п.).
- Можно выбрать несколько фильтров одновременно (пересечение условий).
- Кнопка «Применить» возвращает на список фруктов с обновлёнными настройками.

### 5.3. Экран «Детальная информация о фрукте»

- Заголовок: название фрукта.
- Поля:
  - Family;
  - Order;
  - Genus;
  - нутриенты: Calories, Fat, Sugar, Carbohydrates, Protein.
- Крупная иконка добавления/удаления из избранного.
- Визуально выделенный блок с питательной ценностью.

### 5.4. Вкладка «Избранное»

- Отображает только те фрукты, ID которых сохранены в локальном хранилище.
- Состояния:
  - загрузка (лоадер);
  - «Вы пока ничего не добавили в избранное» - если список пуст;
  - ошибка + кнопка «Перезагрузить»;
  - список избранных фруктов.
- Карточка избранного:
  - название;
  - иконка удаления из избранного;
  - переход в детальную карточку по нажатию.

### 5.5. Вкладка «Рецепты»

- Загрузка рецептов из локального хранилища.
- Состояния:
  - загрузка;
  - ошибка + кнопка «Перезагрузить»;
  - «Создайте свой первый рецепт» - если рецептов нет;
  - список рецептов.

Карточка рецепта:

- название;
- короткое описание (обрезается по длине);
- состав - перечисление фруктов строкой;
- итог по нутриентам (сумма по всем фруктам в рецепте);
- иконка удаления;
- иконка/кнопка для открытия полного рецепта.

### 5.6. Экран создания/редактирования рецепта

- Поле «Название рецепта» (обязательное, валидация на непустое значение);
- Поле «Описание» (опциональное, многострочное);
- Список фруктов из избранного с чекбоксами/переключателями;
- Кнопка «Сохранить»:
  - при создании - создаёт новый рецепт;
  - при редактировании - обновляет существующий в локальном хранилище.

### 5.7. Экран просмотра рецепта

- Название и описание рецепта;
- Список фруктов в составе;
- Блок с суммарными нутриентами;
- Кнопка «Редактировать рецепт».
